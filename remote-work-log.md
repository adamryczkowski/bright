### Root Cause

The config file `~/.config/bright/config.toml` was generated before the auto-detection feature was added. It contains:
```toml

```

This explicit setting overrides the new default of `backend = "auto"`.

The user needs to either:
1. Edit the config file and change `backend = "openrgb-cli"` to `backend = "auto"`
2. Or delete the config file (`rm ~/.config/bright/config.toml`) and let it regenerate with the new defaults
3. Or explicitly set `backend = "brightnessctl"` in the config file

## Session: 2026-01-11 - Fixing pipx installation permission error

### Connection Details
- Host: 192.168.42.210 (mango)
- User: sofia
- Connection ID: mango-sofia

### Problem

When running `pipx install git+https://github.com/adamryczkowski/bright --force`, the installation failed with:

```
PermissionError: [Errno 13] Permission denied: '/home/adam/.local/share/pipx/venvs/yt-dlp/share/man/man1'
```

### Investigation

**Intention:** Investigate why pipx installation was failing with a permission error.

**Commands executed:**

1. `ls -la ~/.local/share/pipx/venvs/yt-dlp/share/man/`
   - Output: `No such file or directory (os error 2)`
   - Interpretation: The yt-dlp man directory doesn't exist in sofia's pipx venvs

2. `ls -la ~/.local/share/man/man1/`
   - Output:
     ```
     tldr.1 -> /home/sofia/.local/share/pipx/venvs/tldr/share/man/man1/tldr.1
     yt-dlp.1 -> /home/adam/.local/share/pipx/venvs/yt-dlp/share/man/man1/yt-dlp.1
     ```
   - Interpretation: **ROOT CAUSE FOUND** - There's a symlink in sofia's man directory pointing to adam's pipx venv, which sofia doesn't have permission to access.

### Root Cause

In sofia's global man directory (`~/.local/share/man/man1/`), there was a broken cross-user symlink:
```
yt-dlp.1 -> /home/adam/.local/share/pipx/venvs/yt-dlp/share/man/man1/yt-dlp.1
```

This symlink points to adam's pipx venv directory, which sofia doesn't have permission to access. When pipx runs, it scans the global man directory and tries to resolve symlinks, causing the PermissionError.

### Solution

Removed the broken symlink:
```bash
rm ~/.local/share/man/man1/yt-dlp.1
```

### Verification

After removing the symlink, the installation succeeded:
```bash
pipx install git+https://github.com/adamryczkowski/bright --force
# Output: installed package bright 1.3.0, installed using Python 3.12.3

bright --version
# Output: bright 1.3.0
```
